# SHIFT

Videojuego diseñado para la game jam con temática **SHIFT**.

## Descripción de diseño (GDD resumido)
- **Concepto**: el jugador progresa a través de cambios de estado ("shifts") que modifican el entorno y el comportamiento de los enemigos.
- **Tema central**: los cambios o *shifts* se representan a nivel visual/sonoro y en la estructura de niveles y ritmo de juego.
- **Mecánica principal**: supervivencia por rondas con cambios dinámicos de reglas en cada fase.
- **Elemento de IA**: los enemigos ajustan su patrón de movimiento y presión en función del rendimiento del jugador, impactando directamente en la experiencia de juego.
- **Plataforma objetivo**: Windows PC.

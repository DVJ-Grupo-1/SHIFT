# SHIFT

Videojuego diseñado para la game jam con temática **WAVES**.

## Descripción de diseño (GDD resumido)
- **Concepto**: el jugador progresa a través de oleadas de desafíos donde cada "wave" modifica el entorno y el comportamiento de los enemigos.
- **Tema central**: las olas se representan tanto a nivel visual/sonoro como en la estructura de niveles y ritmo de juego.
- **Mecánica principal**: supervivencia por rondas con incremento de dificultad en cada oleada.
- **Elemento de IA**: los enemigos ajustan su patrón de movimiento y presión en función del rendimiento del jugador, impactando directamente en la experiencia de juego.
- **Plataforma objetivo**: Windows PC.

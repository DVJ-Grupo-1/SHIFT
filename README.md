# SHIFTBOUND

**Tagline:** *Hackea, posee y sobrevive a cada SHIFT del sistema.*

## Descripción
SHIFTBOUND es un action-stealth top-down para Windows PC en el que controlas una entidad digital atrapada en una instalación automatizada. La mecánica central consiste en hacer **SHIFT de cuerpo**: alternar entre forma digital y robots poseídos para superar seguridad, resolver rutas y llegar al núcleo de escape.

## Mecánicas principales
- **SHIFT de estado**: forma digital (rápida y frágil) ↔ cuerpo robótico (resistente y con habilidades específicas).
- **Posesión táctica**: cada tipo de robot abre opciones distintas (combate, acceso, movilidad).
- **Riesgo/recompensa**: abandonar un cuerpo en mal momento puede bloquear rutas o exponerte.
- **IA reactiva**: guardias y drones cambian patrulla, búsqueda y bloqueo según tus patrones de juego.

## Tecnología y plataforma
- **Motor:** Godot (preferente)
- **Plataforma objetivo:** Windows PC
